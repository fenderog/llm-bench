# Voxel Horse Run

A self-contained Godot 4.7.2 scene: a procedurally built block horse runs in place with animated legs, head, tail, and body. No assets or plugins are needed.

## Run

From this directory, run `godot --path .` (or open this directory's `project.godot` in Godot 4.7.2 and press F6/F5). The main scene starts automatically with F5.

## Check import

Run `godot --headless --path . --editor --quit` from this directory.
