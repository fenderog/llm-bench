# Voxel Horse Run

A self-contained Godot 4.7.2 scene: a block-built horse runs in place on a track. The horse, track, lighting, and camera are created in GDScript; no assets or plugins are needed.

## Run

From this directory (`high/`), with Godot 4.7.2 installed:

```sh
godot --path .
```

To open the editor instead, run `godot --editor --path .` and press F5 (the main scene is configured). To check imports headlessly, run `godot --headless --path . --editor --quit`.
