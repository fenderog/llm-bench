# Voxel Horse Run

A self-contained Godot 4.7.2 scene: a horse built from colored boxes runs in place with a diagonal gait, bending knees, bobbing body and head, and swinging tail. No assets or plugins required.

## Run

From this directory, run `godot --path .` (or open this directory in Godot 4.7.2 and press **F6** on `scenes/main.tscn` / **F5** to run the project). On systems where the executable is called `godot4`, substitute `godot4`.

## Check project import

`godot --headless --path . --editor --quit`
