# Rubik's Cube (three.js)

Interactive 3×3 Rubik's Cube rendered with three.js.

- Drag to orbit, scroll to zoom.
- Buttons or keys `U D L R F B` turn faces (hold Shift for counter‑clockwise).
- `Space` / **Scramble** scrambles; **Solve** replays all moves in reverse.

Entry: `index.html` → `main.js`.
