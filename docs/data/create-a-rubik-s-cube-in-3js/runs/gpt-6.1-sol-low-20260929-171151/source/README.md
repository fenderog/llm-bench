# Cube Lab

An offline-ready, interactive Three.js Rubik’s cube with animated face turns, orbit controls, scramble, undo, reset, and session stats.

Drag to orbit and scroll to zoom. Use the face buttons or U/D/L/R/F/B keys to turn a face; hold Shift for a reverse turn.

Dependencies: `npm install`. Serve with an ES-module-compatible bundler such as Vite (`npx vite`). Entry point: `index.html`.
