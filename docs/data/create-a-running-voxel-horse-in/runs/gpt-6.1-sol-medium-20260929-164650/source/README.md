# Dust & Thunder

A self-contained Godot 4 voxel horse runner through Copper Canyon. All models, scenery, animation and interface are generated in code; no assets or plugins are required.

## Run
Open `project.godot` in Godot 4.7.2 and press **F6/F5**, or run:

```sh
godot --path .
```

Click **Ride the Trail** or press **Space** to begin. **A/D** or **Left/Right** change lanes; **Space**, **W**, or **Up** jump over rails. Collect golden horseshoes. **P/Escape** pauses and **R** restarts. The on-screen buttons also support mouse/touch input. Speed increases with distance; your best distance is tracked for the current session.

Uses GL Compatibility rendering and no threads, external dependencies, or downloads. Ready for a standard Godot web export (export is not included).
