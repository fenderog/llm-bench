# Voxel Runner Sandbox (Godot 4.7.2)

A tiny voxel character running around in a small fenced sandbox. 100% procedural — no external assets.

## Run

1. Open this folder in Godot 4.7.2.
2. Press **F5** (main scene is already set to `main.tscn`).
3. Or from a terminal: `godot --path .`

## Controls

- Click the game window to capture the mouse (mouse looks around).
- **WASD / arrows**: run around (camera-relative).
- **Space**: jump.
- **Shift**: sprint.
- **Esc**: release the mouse.

Collect the 6 spinning gold coins scattered around the sandbox!
